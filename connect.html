Setup

The InfluxDB token never touches this page or the dashboard — it lives only as a server-side environment variable on Vercel, read by the /api/live-data function.

  1. In the Vercel dashboard, open this project → Settings → Environment Variables.
  2. Add INFLUX_URL, INFLUX_TOKEN (read-only token), INFLUX_ORG, INFLUX_BUCKET, INFLUX_SITE_ID (the id tag identifying this mill).
  3. Redeploy. This page will show reachable once it's working.
  4. If field names don't match your InfluxDB tags, edit api/_fieldMap.js in the repo with the real measurement/field names, then push — Vercel redeploys automatically.
